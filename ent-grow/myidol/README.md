# MY IDOL 마이아이돌 — 데모 웹사이트

데뷔 전 연습생의 **성장 기록 · 팬 응원 · 스카우팅**을 한곳에서 다루는 B2B2C SaaS 데모입니다.
빌드 도구 없이 HTML/CSS/JS만으로 동작하며, 모든 데이터는 브라우저 저장소(`localStorage`)에 보관됩니다.

- 메인: `index.html`
- 공개: `explore.html` (연습생 둘러보기), `profile.html?id=harin` (공개 프로필)
- 대시보드: `trainee.html` · `fan.html` · `ent.html`
- 등장 인물·수치·기록은 **전부 가상 데모 데이터**입니다.

## 실행 방법

가장 간단한 방법:

```bat
start.bat
```

`start.bat`은 Node.js로 로컬 서버를 띄우고 브라우저를 엽니다. Node가 없다면 `index.html`을 더블클릭해도 대부분 동작하지만, 브라우저에 따라 `file://` 환경의 저장소가 제한될 수 있어 로컬 서버 실행을 권장합니다.

직접 실행:

```bash
cd myidol
node server.js
# http://localhost:4800
```

포트를 바꾸려면 `PORT=5000 node server.js` (Windows PowerShell: `$env:PORT=5000; node server.js`).

## 데모 계정

로그인 화면의 **데모 계정 버튼**을 누르면 비밀번호 없이 바로 입장합니다. 아래 계정은 이메일·비밀번호 입력 로그인에도 사용할 수 있습니다.

| 역할 | 이름 | 이메일 | 비밀번호 |
|---|---|---|---|
| 연습생 | 서하린 | `harin@myidol.kr` | `demo1234` (4자 이상이면 아무 값) |
| 팬 | 김민지 | `fan@myidol.kr` | `demo1234` |
| 엔터 | 이준호 | `scout@myidol.kr` | `demo1234` |

- 역할이 다른 대시보드에 접속하면 전용 게이트가 뜨고, 해당 역할의 데모로 바로 전환할 수 있습니다.
- 로그인·회원가입은 실제 계정을 만들지 않으며 결제도 발생하지 않습니다.

## 역할별 기능

### 연습생 (`trainee.html`)
- **오버뷰**: EGI·팬·기록·연습시간 KPI, 12주 성장 곡선, 연습 히트맵, 최근 기록, 마일스톤, 받은 응원, 다음 일정
- **성장 리포트**: EGI/팬 추이, 스킬 레이더·바, 18주 히트맵, 마일스톤, **포트폴리오 HTML 다운로드**, 인쇄
- **내 기록**: 사진/영상 필터, 기록 열람·댓글, 내가 올린 기록 삭제
- **기록 올리기**: 드래그 앤 드롭 업로드, 이미지 자동 리사이즈(최대 1400px → JPEG), 영상 미리보기, 태그, 공개 범위(팬/소속사/비공개)
- **응원 · 댓글**: 내 기록에 달린 팬·기획사 댓글, 내가 남긴 댓글, 응원 키워드
- **프로필 설정**: 활동명·포지션·소속사·소개·태그 편집, 커버 아트 변경, 공개 범위 스위치(저장됨)

### 팬 (`fan.html`)
- **피드**: 관심 연습생의 최신 사진·영상, 사진/영상 필터, 주간 응원 리포트, 다음 이벤트
- **관심 연습생**: 카드형 목록, 관심 해제, 알림 설정
- **연습생 찾기**: 포지션 필터·검색·정렬, 관심 등록(하트)
- **멤버십**: 멤버 카드, 월간/연간 요금 전환, 응원 활동, 혜택, 해지 모달

### 엔터 (`ent.html`)
- **스카우트 보드**: KPI, 관심 후보 비교, 후보 상세(스킬·메모), 전체 후보 테이블
- **관심 후보**: 검색·포지션·정렬, 별표 등록, 후보 요약, 비공개 검토 메모
- **팬 · 성장 분석**: 팬 규모/증가 비교, 12주 팬 추이, 팬 구성, 포지션 분포, CSV 내보내기
- **리포트**: 후보별 스카우트 리포트(인쇄용 A4 스타일), **HTML 저장**, 선택 후보 전환

## 저장·초기화

- 키 이름: `myidol.v1.session`, `myidol.v1.extraPosts`, `myidol.v1.favorites`, `myidol.v1.comments`, `myidol.v1.likes`, `myidol.v1.profiles`, `myidol.v1.memos`
- 초기화: 브라우저 개발자 도구 콘솔에서 `localStorage.clear()` 후 새로고침
- 이미지 업로드는 data URL로 저장됩니다. 브라우저 저장 공간이 부족하면 현재 세션(메모리)에만 유지되고 안내 토스트가 표시됩니다.
- 영상 업로드는 미리보기만 제공하며 파일 자체는 저장하지 않습니다.

## 파일 구조

```
myidol/
├─ index.html / explore.html / profile.html
├─ trainee.html / fan.html / ent.html
├─ server.js / start.bat
└─ assets/
   ├─ css/base.css   디자인 토큰·공통 컴포넌트
   ├─ css/site.css   랜딩·탐색·공개 프로필
   ├─ css/app.css    대시보드·리포트·인쇄
   └─ js/
      ├─ data.js     데모 데이터셋(오늘 기준 날짜 자동 계산)
      ├─ store.js    세션·기록·관심·댓글·메모 저장소
      ├─ ui.js       공통 UI(아트워크, 차트, 모달, 인증)
      ├─ site.js     랜딩·탐색·공개 프로필
      └─ app.js      역할별 대시보드 라우터·화면
```

## 참고

- 커버 이미지는 생성형 인물 사진 대신, 이니셜·듀오톤·링·그레인으로 구성한 일관된 아트워크 시스템을 사용합니다.
- 데이터의 날짜는 접속일 기준으로 계산되어 D-day와 최근 기록이 항상 최신으로 보입니다.
- 인쇄(PDF 저장)는 브라우저 인쇄 대화상자를 사용합니다. 리포트 화면에서 `인쇄` → `PDF로 저장`을 선택하세요.
- 이 사이트는 포트폴리오/시연용이며 실제 결제, 본인 인증, 서버 저장 기능은 포함하지 않습니다.
